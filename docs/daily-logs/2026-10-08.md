## 一、需求与架构规划

### 1. 背景与痛点分析
在实现了 TrajectoryEventBus 事件总线、Docker/Podman 容器隔离沙箱、SWE-bench 基准评测适配器、AST 语义断言器以及实时 Web 遥测服务端后，`agent-harness` 具备了完整的确定性执行、离线回放与自动化报告能力。但在面向长链路、多轮工具交互与复杂自主智能体评测与调优过程中，开发者与评估人员仍面临以下关键挑战：
- **智能体不可控与调试黑盒**：长链路智能体在多轮迭代中容易陷入逻辑死循环、产生幻觉频繁执行错误命令，传统 Harness 只能等待超时或预算耗尽后抛出失败，缺乏类似调试器（Debugger）的暂停与单步审查能力；
- **缺乏 Human-in-the-Loop (HITL) 动态干预通道**：当智能体偏离正确解题方向或准备执行高危操作时，开发者无法在不中断整个评测流水线的前提下，动态注入提示词纠偏（Prompt Guidance）或篡改工具执行结果（Mock Override）；
- **缺乏多维条件断点机制**：难以针对特定工具名称（如 `bash`、`rm -rf`）、参数匹配、连续报错次数阈值、Turn 轮次深度或 Token 预算水位设定细粒度断点；
- **遥测面板缺乏双向控制交互**：先前的 Web Dashboard 仅具备单向观察流（SSE Read-only），无法在浏览器大屏上一键暂停、恢复、跳过工具或安全中止评测。

### 2. 架构设计与实现方案
围绕 **交互式转向与动态断点调试引擎 (Interactive Steering & Breakpoint Engine)** 进行全链路架构设计与落地：
- **契约规范与自适应 Schema (`src/steering/types.ts`, `src/steering/schemas.ts`)**：
  - 定义 `BreakpointRule`（支持 `tool`、`error_count`、`turn`、`budget_ratio`、`custom` 五大断点类型与 `argumentMatch` 参数匹配、`once` 单次触发、`enabled` 开关）；
  - 定义 `InterventionAction`（支持 `continue`、`inject_prompt`、`override_tool`、`skip_tool`、`abort` 五大干预动作类型）；
  - 扩展 `src/events/types.ts`，引入 `breakpoint:hit`、`breakpoint:resume` 与 `steering:action` 事件类型。
- **动态条件断点规则匹配引擎 (`src/steering/engine.ts`)**：
  - 实现 `BreakpointEngine`，维护断点规则的增删改查、启用/禁用状态与命中计数（`hitCount`）；
  - 提供异步非阻塞 `evaluate(context)`，综合评估工具名正则匹配、入参断言、连续错误计数、轮次阈值、预算消耗比率与自定义谓词。
- **转向状态机与拦截控制器 (`src/steering/controller.ts`)**：
  - 维护核心状态机（`idle` -> `running` -> `paused` -> `resumed` / `aborted`）；
  - 命中断点时挂起执行 Promise，广播 `breakpoint:hit` 事件；
  - 接收外部干预指令后恢复执行，分发 `overrideResult`、`skipResult`、维护注入提示词队列（`consumeInjectedPrompts`），或安全抛出 `SteeringAbortError`；
  - 追踪连续错误计数 `consecutiveErrors`，执行成功自动归零。
- **核心运行时与工具分发层深度集成 (`src/mock/dispatcher.ts`, `src/core/harness.ts`)**：
  - `VirtualToolDispatcher` 工具调用生命周期集成 Steering 钩子，支持在工具原生执行前拦截、覆写或跳过；
  - `AgentHarness.runScenario` 上下文注入 `steering` 实例，处理 `aborted` 轨迹生命周期状态。
- **遥测控制 REST API 与双向交互 Web 控制台 (`src/telemetry/server.ts`, `src/telemetry/dashboard.ts`)**：
  - TelemetryServer 新增 `/api/control/*` 端点（`state`, `pause`, `resume`, `intervene`, `breakpoint`）；
  - Web Dashboard 嵌入黑曜石暗色风格 Interactive Steering 控制面板，展示黄色断点报警条与一键 Resume、Inject Prompt、Skip Tool、Abort 控制按钮。
- **CLI 命令行交互参数支持 (`src/cli/index.ts`)**：
  - `agent-harness run` 增加 `-i, --interactive` 与 `--breakpoint <rules...>` 参数，快速启动断点调试。
