## 一、需求与架构规划

### 1. 背景与痛点分析
在实现了 TrajectoryEventBus 流式事件总线、容器沙箱隔离、SWE-bench 基准适配器、AST 语义断言器、Web 遥测大屏以及交互式断点转向控制器后，`agent-harness` 已具备成熟的执行、评测与调试能力。但在面临多轮迭代评测、Prompt 版本升级对比、底层大模型基准选型（如 Claude 3.5 Sonnet vs GPT-4o 对比）以及人类干预（HITL）调优效果验证时，开发者面临严重的评估盲区：
- **二元断言结果掩盖过程退化**：仅凭最终通过/失败（Pass/Fail）无法感知智能体在执行链路中的隐蔽退化（如多消耗了 3 倍 Token、多经历了 5 轮死循环尝试后勉强成功等）；
- **执行步骤无序与对齐困难**：自主智能体具有探索性，常会在关键操作前后插入无害探测命令（如 `ls`、`pwd`、`cat`），简单的逐行对比会产生雪崩式错位，无法准确对齐等价操作；
- **缺乏首个分歧点根因定位**：当 Candidate 轨迹偏离 Baseline 成功路径时，排查人员需要手动比对上百行 JSON 寻找分歧起源；
- **缺乏自动化防回归 CI 门禁**：无法在 CI/CD 流水线中基于语义退化、Token 激增或死循环行为自动阻断 PR 合并；
- **缺乏多端可视化差分报告**：缺少适用于终端直观审查、GitHub PR 评论以及浏览器大屏展示的差分对比呈现。

### 2. 架构设计与实现方案
围绕 **差分轨迹对比与回归分析引擎 (Differential Trajectory Comparator & Regression Analyzer)** 进行系统化设计与实现：
- **类型契约与 Schema 校验 (`src/comparator/types.ts`, `src/comparator/schemas.ts`)**：
  - 定义 `TrajectoryStepSummary`、`AlignedStep`、`DivergencePoint`、`RegressionSeverity`、`TrajectoryAnomaly`、`TrajectoryDiff` 等核心接口契约；
  - 覆盖 `tool_mismatch`、`arg_mismatch`、`tool_failure`、`status_regression`、`loop_detected`、`premature_exit` 等 7 种分歧类型；
  - 制定 5 级回归严重度标准：`identical`、`equivalent`、`minor_drift`、`regression`、`critical_failure`。
- **自适应动态序列对齐算法 (`src/comparator/alignment.ts`)**：
  - 将 Trajectory 线性展开为原子步骤序列（工具调用与思考/终结消息）；
  - 基于 Needleman-Wunsch 动态规划全局序列对齐算法，结合工具名、Jaccard 词袋相似度及结果状态构建相似度矩阵，准确处理步骤的新增 (`added`)、删除 (`removed`)、变异 (`modified`) 与完全匹配 (`match`)。
- **深度回归归因与异常异动检测器 (`src/comparator/analyzer.ts`)**：
  - 自动检测并输出**首个分歧点 (First Divergence Step)**，定位偏离发生源头；
  - 五大异常异动检测：
    - `loop_detected`：同参数死循环连续调用 $\ge 3$ 次；
    - `error_spike`：工具执行失败率显著上升；
    - `token_explosion`：Token 消耗较基线膨胀超过阈值（如 $+50\%$）；
    - `empty_turn`：无效空轮次；
    - `rapid_failure`：前 1~2 轮内早夭崩溃。
  - 综合序列对齐率、状态迁移与异常惩罚计算回归严重度综合评分（0.0 ~ 1.0）。
- **统一对比器核心与报告差分 (`src/comparator/comparator.ts`)**：
  - `TrajectoryComparator.compare(baseline, candidate, options)`：全量轨迹对比；
  - `TrajectoryComparator.compareReports(baseReport, candReport)`：断言状态迁移矩阵比对（`maintained_pass`、`maintained_fail`、`regression`、`improvement`）。
- **多格式可视化差分渲染器 (`src/comparator/reporters/*`)**：
  - `terminal`：高亮 ANSI 颜色对比，输出指标比对、分歧警报与带状态徽章的逐步对齐表；
  - `markdown`：适配 GitHub PR 的 Markdown 表格，包含指标矩阵与对齐详情；
  - `html`：黑曜石暗黑极简风格的自包含 HTML 大屏报告，内置指标卡与响应式表格；
  - `json`：机器可读的结构化输出。
- **CLI 命令行扩展与 CI 质量门禁 (`src/cli/index.ts`)**：
  - 增加 `agent-harness diff <baseline> <candidate>` 命令行指令；
  - 支持 `-f, --format <terminal|markdown|html|json>`、`-o, --output <path>`；
  - 提供 `--fail-on-regression` 门禁参数，当检测到功能退化时退出码返回 `1`。
