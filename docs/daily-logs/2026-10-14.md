## 一、需求与架构规划

### 1. 背景与痛点分析
在完成了断言校验器、混沌工程故障注入、多轨迹集群共识挖掘以及策略蒸馏引导引擎之后，`agent-harness` 已经具备了完整的离线评测与运行时动态干预能力。但在针对自主智能体（Autonomous Agents）构建自我演进与综合评测闭环时，仍面临关键瓶颈：
- **静态基准测试存在数据泄漏与过拟合风险**：现有的 SWE-bench 或静态场景脚本大多采用固定的文件组织结构、提示词指令与严格断言，模型容易记住特定文件路径甚至产生过拟合，缺乏在受控随机扰动下的鲁棒性泛化验证；
- **“诊断发现弱点”与“定向训练演练”脱节**：系统此前虽然能通过 Verifier 和 Trajectory 抓取到智能体的具体失败点（如 AST 语法回归、高危命令违规、预算耗尽死循环、工作区相对路径混淆），但缺乏自动根据弱点画像反向合成测试场景的闭环手段；
- **缺乏动态阶梯演进关卡与晋级机制 (Auto-Curriculum Progression)**：真实的工程能力评估需要循序渐进的难度梯度（从新手提示引导、到进阶工程约束、再到极限边界与对抗干扰），并依据当前关卡通过率实行自适应晋级准入（Adaptive Gating）；
- **策略蒸馏引导的闭环增益缺乏定量度量**：前日落地的策略蒸馏先验虽然可输出动态提示词与拦截断点，但缺乏将先验策略挂载回执行上下文并在变异关卡中定量对比 Baseline 与 Guided 表现（通过率提升幅度 Uplift、弱点自愈率）的闭环验证引擎。

### 2. 架构设计与实现方案
系统化设计并实现了 **自适应任务合成与闭环自演进演练引擎 (`src/curriculum`)**：
- **核心契约与 Schema 规范 (`src/curriculum/types.ts`, `src/curriculum/schemas.ts`)**：
  - 定义四阶演练难度等级 `CurriculumDifficultyLevel`（`novice`、`intermediate`、`advanced`、`adversarial`）；
  - 定义七大弱点分类 `WeaknessCategory`（`ast_syntax_error`、`security_violation`、`infinite_loop`、`budget_exhaustion`、`command_flakiness`、`file_integrity`、`tool_format_error`）；
  - 定义四维变异维度 `MutationDimension`（`instruction`、`workspace`、`verifier`、`environment`）与变异记录 `AppliedMutationRecord`；
  - 定义弱点画像模型 `WeaknessProfile`、演练阶段 `CurriculumStage`、完整天梯计划 `CurriculumPlan` 与执行结果 `CurriculumResult`，全面通过 Zod 强类型校验。
- **确定性变异合成器矩阵 (`src/curriculum/mutators/*`)**：
  - `SeededPRNG`：基于 Mulberry32 算法的高性能确定性伪随机数发生器，确保给定 seed 下变异任务完全可复现；
  - `InstructionMutator`：提示词维度变异（novice 注入分步提示、intermediate 追加向后兼容与签名约束、advanced 注入边界极限条件、adversarial 注入误导性干扰与反欺骗指令）；
  - `WorkspaceMutator`：文件空间维度变异（按难度自动注入规范指南文件、配置项、诱饵废弃文件或深层嵌套目录）；
  - `VerifierMutator`：断言与预算维度变异（自适应收紧或放宽 `maxTurns`、`timeoutMs`、`maxTokens`，并针对安全与步数注入轨迹断言）；
  - `EnvironmentMutator`：沙箱环境维度变异（动态扩充高危命令黑名单、对抗模式下收紧全局通配符白名单）；
  - `TaskSynthesizer`：统筹四维变异，提供单任务合成 `synthesize`、批量变异 `synthesizeBatch` 以及自动化四阶梯计划生成 `generateCurriculumPlan`。
- **弱点漏洞诊断画像器 (`src/curriculum/profiler.ts`)**：
  - `WeaknessProfiler`：自动聚类解析多轮 `HarnessReport` 断言失败日志与指标，量化各弱点出现频率与归一化脆弱度分值，智能推荐适配的演练起始难度关卡。
- **闭环演练执行器与能力评级状态机 (`src/curriculum/runner.ts`)**：
  - `AutoCurriculumRunner`：
    - 支持直接驱动 `AgentAdapter` 接口或通用函数执行上下文；
    - 执行关卡自适应门禁（Gating）：当某阶段通过率未达阈值（如 $< 75\%$）时自动阻断前行；
    - Elo 能力积分演进：结合各阶段难度乘数（0.8 ~ 2.0）与预期达成率动态计算智能体能力评分增长值 ($\Delta$)；
    - 无缝挂载策略蒸馏模块 `DistilledPolicy` 与 `DynamicGuidanceDispatcher`，在执行高阶任务时动态拦截违规操作并下发提示；
    - 输出自愈增益分析 `RemediationMetrics`（Baseline vs Guided 通过率、提升百分比 Uplift 与各弱点类别修复判定）。
- **统一门面与多端报告器 (`src/curriculum/engine.ts`, `src/curriculum/reporters/*`)**：
  - `AutoCurriculumEngine` 提供统筹入口门面；
  - 提供 `terminal`（高亮 ANSI 关卡天梯、能力评级卡片与弱点自愈矩阵）、`markdown`（标准化表格）及 `json` 报告器。
- **CLI 命令行生态扩展 (`agent-harness curriculum`)**：
  - 新增 `agent-harness curriculum` 命令，支持 `--scenario`、`--stages`、`--scenarios-per-stage`、`--guidance`、`--format`、`--output`、`--export-plan`、`--min-competency` 等参数。
