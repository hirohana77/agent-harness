## 一、需求与架构规划

### 1. 背景与痛点分析
在实现 SWE-bench 适配器与 Docker / Podman 虚拟化沙箱的基础上，评测自主编码智能体（如代码补全、缺陷修复、接口重构）生成的代码质量与结构正确性时，传统的文本行比对与正则表达式匹配面临以下根本性缺陷：
- **格式与空白字符脆弱性**：缩进、空行、单双引号、换行风格（CRLF/LF）与分号风格的细微变动极易导致纯文本断言产生假阴性（False Negative）；
- **注释与伪匹配干扰**：被注释的代码（如 `// function calculateDiscount()`）使用正则表达式匹配时会产生假阳性（False Positive）；
- **多种等价语法变体无法统一捕获**：函数可能表现为 `function foo()`、`const foo = () => {}`、`const foo = function() {}` 或 Class method，纯正则无法完备覆盖其修饰符（`async`、`generator`、`export`、`static` 等）；
- **缺乏类型与接口语义断言**：无法验证 TypeScript 中类是否正确继承基类、是否完整实现接口签名（`implements IService`）、属性是否可选或匹配类型；
- **缺乏反模式与复杂度门禁**：在高质量代码重构任务中，智能体可能残留脏代码（如 `eval()`、`debugger`、`console.log`、`any` 类型、`var` 声明、空 `catch` 块、多层嵌套三元运算符），且传统断言无法对函数圈复杂度（Cyclomatic Complexity）与 AST 最大嵌套深度进行自动化门禁拦截。

### 2. 架构设计与实现方案
围绕 **AST 语法树语义断言与代码结构分析引擎（AST Semantic Assertion Engine）** 进行全链路架构升级：
- **契约规范与自适应 Schema (`src/verifier/ast/types.ts` & `src/verifier/ast/schemas.ts`)**：
  - 定义 `ASTAssertionRule` 辨识联合（Discriminated Union），支持 9 大核心规则契约：
    1. `has_function`：断言函数存在性、参数列表、参数数量上下界、`async` / `generator` / `export` 状态及返回类型；
    2. `has_class`：断言类名、导出状态、抽象类标识、`extendsClass` 继承链、`implementsInterfaces` 接口实现、类方法与属性；
    3. `has_interface`：断言 TypeScript 接口、继承接口、属性类型及可选性；
    4. `has_type_alias`：断言类型别名；
    5. `has_import`：断言模块导入来源、默认导入、命名导入与命名空间导入；
    6. `has_export`：断言命名导出与默认导出；
    7. `no_forbidden_syntax`：反模式与代码异味扫描（`eval`, `debugger`, `console`, `any_type`, `var_declaration`, `empty_catch`, `nested_ternary`）；
    8. `complexity`：圈复杂度与 AST 深度阈值门禁；
    9. `custom_query`：指定 SyntaxKind 节点频次过滤与上下界验证。
  - 扩展核心 `ScenarioAssertionsSchema` 与 `AssertionItemResultSchema`，无缝纳入 `'ast'` 类型。
- **高性能 AST 解析与缓存机制 (`src/verifier/ast/parser.ts`)**：
  - 基于官方 TypeScript Compiler API (`ts.createSourceFile`)，支持 `.ts`、`.tsx`、`.js`、`.jsx`、`.mjs`、`.cjs` 自动 ScriptKind 推导；
  - 内置 LRU / 内容哈希内存缓存机制，同文件多规则并发断言时零重复解析。
- **深度代码语义提取与反模式分析引擎 (`src/verifier/ast/analyzer.ts`)**：
  - `findFunctions` / `findClasses` / `findInterfaces`：完备支持函数声明、变量箭头函数赋值与类方法统一抽象，接口成员兼容 `MethodSignature` 与 `PropertySignature`；
  - `detectAntiPatterns`：递归扫描并精准定位代码异味，支持括号解包识别嵌套三元运算符；
  - `computeComplexity`：精准计算分支判断语句（`if`、`while`、`for`、`case`、`catch`、三元条件、`&&`、`||`、`??`）构成的圈复杂度与语法树层级深度。
- **工作区验证器与核心执行器集成 (`src/verifier/ast-verifier.ts` & `src/verifier/index.ts`)**：
  - `ASTVerifier`：集成 `WorkspaceManager`，提供文件容错边界与详细的诊断错误消息；
  - `ScenarioVerifier`：核心流水线一键串联 `ast` 断言，输出统一的标准 Harness 报告。
- **CLI 模板与生态接入 (`src/cli/index.ts`)**：
  - 扩展 `agent-harness init` 场景脚手架模板，默认包含标准 AST 结构断言示例。
