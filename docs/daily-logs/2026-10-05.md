## 一、需求与架构规划

### 1. 背景与痛点分析
在实现了 TrajectoryEventBus 事件总线、Docker/Podman 容器隔离沙箱、SWE-bench 基准评测适配器以及 AST 语法树语义断言器后，`agent-harness` 已具备完备的评测与断言执行能力。然而，在长时间或大规模评测自主智能体（例如解决复杂工程问题、多轮工具交互执行）时，开发与评测人员面临以下体验与工程痛点：
- **终端信息过载与观察死角**：长轨迹执行时，海量日志迅速刷屏，难以即时洞察当前智能体所处的具体 Turn、最新工具调用入参与返回值；
- **缺乏实时浏览器可视化监控面板**：传统测试工具多为终端输出或执行完成后生成离线报告，无法在评测进行中通过可视化仪表盘实时观测 Agent 思考与执行动态；
- **外部监控工具集成成本高**：多数方案需要依赖复杂的外部中间件（如 Redis、Kafka、Prometheus），导致测试沙箱与评估环境轻量化部署困难；
- **网络抖动与断线丢失事件**：在远程监控多机评测或分布式工作节点时，SSE 订阅客户端容易因网络瞬断导致事件丢失，缺少开箱即用的事件环形缓冲区（Ring Buffer）与 `Last-Event-ID` 重连回放机制；
- **异构与分布式上报缺失**：外部智能体运行时、沙箱隔离环境或分布式 Worker 缺乏标准轻量级 HTTP 遥测数据摄取接口。

### 2. 架构设计与实现方案
围绕 **实时 Web 遥测服务端与 SSE 监控面板（Live Telemetry & Web Dashboard Engine）** 进行全链路架构设计与实现：
- **契约规范与自适应 Schema (`src/telemetry/types.ts`)**：
  - 定义 `TelemetryServerConfig`、`TelemetryServerStats`、`SSEClientInfo` 与 `TelemetryEventHistoryQuery` 核心类型契约；
  - 基于 Zod 严格校验服务端配置与 HTTP POST 事件摄取数据格式（`TelemetryIngestEventSchema`）；
  - 全局导出至包入口 `src/index.ts`。
- **高吞吐环形事件缓冲区 (`src/telemetry/ring-buffer.ts`)**：
  - 实现定长 `EventRingBuffer`，支持 O(1) 循环入队与溢出自动淘汰；
  - 提供 `getSinceId()` 索引检索，精准定位断线客户端遗漏的历史事件并高效切片回放；
  - 支持按 `limit`、`type`（通配符 `tool:*` 等）、`scenarioId` 进行灵活历史过滤查询。
- **内嵌零外部依赖 Web 仪表盘 (`src/telemetry/dashboard.ts`)**：
  - 原生 HTML5 + CSS3 + Vanilla JavaScript 实现现代化黑曜石暗色风格大屏，完全不依赖任何外部 CDN，支持在完全断网与沙箱离线环境中稳定渲染；
  - 动态呈现实时连接状态指示灯（在线/重连中/断开）、执行轮次、Token 消耗、工具调用频次、耗时、AST 语义断言检查清单；
  - 支持按事件类别（All、Tools、Turns、Scenario、Errors）动态筛选、暂停/开启自动滚动，并可点击展开格式化 JSON 原始事件载荷。
- **高性能 Server-Sent Events 流式广播器 (`src/telemetry/sse.ts`)**：
  - 维护动态客户端连接池，管理 SSE 握手响应头；
  - 自动心跳保活定时器（`: keepalive\n\n`），有效防止 Nginx/代理中间件超时断开；
  - 自动解析 `Last-Event-ID` 请求头与 URL 参数，实现平滑断线重连补发；
  - 精准捕获并清理死连接，杜绝 Socket 与内存泄漏。
- **轻量级 HTTP 遥测服务与 REST API (`src/telemetry/server.ts`)**：
  - 基于 Node.js 原生 `node:http` 实现轻量高效的路由处理，内置 CORS 全面支持与安全 Bearer 认证；
  - 暴露端点：
    - `GET /` & `GET /dashboard`：实时 Web 监控面板；
    - `GET /api/events`：SSE 实时事件流通道；
    - `GET /api/status`：服务器运行时间、在线客户端数与内存缓冲指标；
    - `GET /api/history`：按条件检索历史事件流水；
    - `GET /api/report` & `GET /api/trajectory`：最新评测断言报告与轨迹数据；
    - `POST /api/events`：支持分布式评测节点远程上报遥测事件；
  - 优雅停机支持：同步关闭活跃连接与空闲 Keep-Alive 连接，确保端口即刻释放。
- **遥测流观察者适配器 (`src/telemetry/observer.ts`)**：
  - 实现 `TelemetryObserver`（符合 `TrajectoryStreamObserver` 契约），支持进程内直连与远程 HTTP 批量推送两种工作模式。
- **CLI 命令行生态融合 (`src/cli/index.ts`)**：
  - 新增 `agent-harness serve` 命令：一键启动独立遥测与 Web 监控服务端；
  - 扩展 `agent-harness run` 命令：引入 `--telemetry`、`--telemetry-port`、`--telemetry-remote` 与 `--keep-alive` 参数，评测启动时自动拉起 Live Dashboard。
