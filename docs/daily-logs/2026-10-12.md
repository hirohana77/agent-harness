## 一、需求与架构规划

### 1. 背景与痛点分析
在实现了确定性执行沙箱、AST 语义断言、SWE-bench 基准适配器、流式事件总线、动态断点控制器、两两差分轨迹比对（Pairwise Comparator）以及混沌工程韧性评测框架后，`agent-harness` 已经具备了领先的单次与成对智能体执行评估能力。然而，在学术界与工业界的主流评测体系（如 pass@k 采样、Self-Consistency 多数投票、Best-of-N 解法重采样以及多智能体 Swarm 辩论）中，开发者面对的往往是针对同一任务生成的 $N$ 条并行自主轨迹（$N \ge 3$）。这带来了全新的评测瓶颈：
- **两两对比无法全局对齐**：成对比较（Candidate vs Baseline）只能揭示两个单独运行间的局部差异，无法在多个并发 Rollout 间建立统一的时间轴和决策矩阵；
- **探索性试探引发时序错位**：自主智能体具有探索性，不同 Rollout 在解决同一问题时可能插入不同数量的探测命令（如 `ls`、`grep`、`pwd`），缺乏渐进式多序列比对（Multi-Sequence Alignment, MSA）会导致步骤对齐雪崩式错位；
- **难以识别关键检查点与不变瓶颈**：无法自动化识别哪些步骤是所有成功运行所必须通过的“不变瓶颈节点 (Invariant Checkpoints)”，哪些步骤与最终成功率具有强正相关（$r \to 1.0$）；
- **缺乏死循环与致错陷阱挖掘**：在多个失败或退化的轨迹中，缺乏对高频引发报错或安全阻断的“死区陷阱节点 (Dead-End Traps)”的自动聚类与归因；
- **缺乏黄金轨迹蒸馏与合成能力**：缺乏从杂乱的并发采样中剔除单次运行偶发幻觉与死循环重试，提取出置信度最高、步骤最精炼的“规范黄金路径 (Canonical Golden Trajectory)”的算法支持；
- **缺乏集群一致性门禁与多端呈现**：无法在 CI/CD 流水线中基于跨 Rollout 一致性得分（Agreement Score）或决策熵（Path Diversity Entropy）进行自动化质量卡点，也缺少面向终端和 GitHub PR 的直观共识矩阵图表。

### 2. 架构设计与实现方案
围绕 **多轨迹集群共识比对与黄金路径挖掘引擎 (Cluster Trajectory Consensus & Route Mining Engine)** 进行系统化设计与落地（`src/consensus`）：
- **核心接口契约与 Schema 规范 (`src/consensus/types.ts`, `src/consensus/schemas.ts`)**：
  - 定义共识步骤层级 `ConsensusStepLevel`（`invariant`、`majority`、`minority`、`outlier`）；
  - 定义对齐槽位 `ConsensusSlot` 与全局时序对齐列 `AlignedConsensusColumn`；
  - 定义集群综合指标 `TrajectoryClusterMetrics`（包含通过率、跨运行一致性得分、香农路径多样性熵等）；
  - 定义关键检查点 `BottleneckNode`、死区陷阱 `DeadEndTrap` 与规范黄金轨迹 `CanonicalTrajectory` 数据契约；
  - 基于 Zod 实施全链路运行时 Schema 强校验。
- **渐进式多序列比对算法 (Progressive MSA) (`src/consensus/msa.ts`)**：
  - 针对离散工具调用序列，构建基于 Needleman-Wunsch 与 Profile 的全局渐进式对齐模型；
  - 建立指导树排序（Pairwise Similarity Guide Order），动态构建 Profile 矩阵并逐一将剩余轨迹对齐融合；
  - 设计合理的错配惩罚与间隙惩罚（Mismatch vs Gap Penalty），有效容忍探测性试探，避免强行错配；
  - 内置 LRU 式步骤相似度高频缓存（`StepSimilarityCache`），大幅加速大规模轨迹对齐效率。
- **集群共识与陷阱分析器 (`src/consensus/analyzer.ts`)**：
  - 计算集群成功率、平均轮次、平均 Token、跨轨迹一致性综合得分；
  - 引入香农信息熵（Shannon Entropy）量化路径多样性与决策确定性（$H = -\sum p_i \log_2 p_i$）；
  - 基于成功覆盖度与相关系数计算公式挖掘不变瓶颈节点（Invariant Bottlenecks）；
  - 基于失败率阈值聚类死区陷阱节点（Dead-End Traps），并收集提取共性错误日志。
- **规范黄金轨迹合成器 (`src/consensus/synthesizer.ts`)**：
  - 自动剔除单次离群调用、幻觉探针与已识别的死区陷阱；
  - 自动去重连续冗余工具调用（死循环去重）；
  - 保留高置信度共识步骤与关键检查点，重建包含完整 instruction、thought、toolCalls 的标准执行轮次；
  - 计算黄金轨迹综合置信度得分（0~100 分）。
- **多端呈现与 CLI 命令行扩展 (`src/consensus/reporters/*`, `src/cli/index.ts`)**：
  - `terminal`：高亮 ANSI ASCII 对齐矩阵、运行卡片、瓶颈标记与雷达摘要；
  - `markdown`：适配 GitHub PR 评论与 CI 审查的 Markdown 格式表格；
  - `json`：严格 Schema 的完整 MSA 矩阵机器可读导出；
  - CLI 新增 `agent-harness consensus` 指令，支持 `--trajectories`（多文件/目录扫描）、`--format`、`--output`、`--synthesize`（导出黄金轨迹）以及 `--min-score`（CI 门禁阻断）。
