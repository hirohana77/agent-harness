## 一、需求与架构规划

### 1. 背景与痛点分析
在昨日实现 Docker / Podman 虚拟化沙箱执行后端的基础上，评测智能体在复杂实际开源仓库缺陷修复能力的权威基准（SWE-bench / SWE-bench Lite / SWE-bench Verified）仍面临落地阻碍：
- **格式繁杂与序列化不规范**：Hugging Face 官方 SWE-bench JSONL 数据集包含多种历史变体（如 `FAIL_TO_PASS` / `PASS_TO_PASS` 字段在不同版本中存在字符串化 JSON 数组、单引号字符切片与原生数组交织的情况）；
- **环境装配与指令转换繁琐**：SWE-bench 官方镜像（`swebench/sweb.eval.x86_64.<instance_id>`）需自动与 harness 场景规格对接，并将任务说明、golden patch、eval test patch 组织入工作区；
- **评测断言缺乏官方语义闭环**：通用测试执行无法直接输出标准 SWE-bench 维度的指标（`RESOLVED`、`UNRESOLVED`、`REGRESSION` 与测试用例级别的 Fail-to-Pass / Pass-to-Pass 保持率统计）；
- **大数据集内存瓶颈**：全量 SWE-bench 数据集可达数百兆，传统的单次全量内存读取在低规格评测机上容易触发 OOM。

### 2. 架构设计与实现方案
围绕 **SWE-bench 任务集标准化适配器（SWE-bench Adapter & Evaluator）** 体系进行全套架构升级：
- **契约规范与自适应 Schema (`src/benchmark/swebench/types.ts` & `schemas.ts`)**：
  - 定义 `SWEBenchInstance` 契约规范，涵盖 `instance_id`, `repo`, `base_commit`, `problem_statement`, `hints_text`, `patch`, `test_patch`, `FAIL_TO_PASS`, `PASS_TO_PASS`；
  - 构造 `StringListPreprocessed` Zod 宽容预处理器，自适应解析原生数组、序列化 JSON、带引号单项及脏数据；
  - 制定官方预测补丁标准契约 `SWEBenchPrediction` 及评测结果汇总 `SWEBenchSuiteSummary`。
- **核心适配转换与流式引擎 (`src/benchmark/swebench/adapter.ts`)**：
  - `toScenario` / `batchConvert`：一键将 SWE-bench 任务映射为 `ScenarioDefinition`，自动注入 `SWE_BENCH_TASK.md` 提示词上下文、`eval_test.patch` 验证补丁与官方 Docker 镜像配置；
  - `generateEvalCommand`：内置主流开源仓库（Django, SymPy, Scikit-learn 等）的原生测试启动器与自动测试用例拼装；
  - `readJSONLStream`：基于 Node.js `readline` 实现流式行读取与容错跳过机制，支持亿级 Token 场景下内存平稳；
  - `exportScenarios`：支持向指定目录批量导出标准 YAML / JSON 格式场景文件。
- **测试日志语义解析与准确度评测引擎 (`src/benchmark/swebench/evaluator.ts`)**：
  - `parseTestOutput`：内置 ANSI 转义字符清洗，高精度解析 Pytest (`PASSED`, `FAILED`, `SKIPPED`, `XFAIL`, `XPASS`) 与 Python `unittest`（`ok`, `FAIL`, `ERROR`）输出；
  - `evaluateInstance`：严格执行 SWE-bench 双断言判定规则（所有 `FAIL_TO_PASS` 测试必须 100% 通过；所有 `PASS_TO_PASS` 测试必须零回归），分类判定 `RESOLVED`、`REGRESSION`、`UNRESOLVED` 与 `ERROR`；
  - `evaluateSuite`：自动按仓库维度聚合缺陷修复成功率、生成官方评测统计。
- **基准测试执行器与 CLI 命令整合 (`src/benchmark/runner.ts` & `src/cli/index.ts`)**：
  - `BenchmarkRunner.loadScenariosFromDir` 与 `runSuite` 自动识别并加载 `.jsonl` 文件；
  - 新增 `BenchmarkRunner.runSWEBench` 接口，无缝串联 Harness 运行态与 SWE-bench 评估报告；
  - 扩展 CLI 子命令群：
    - `agent-harness swebench info -i <dataset.jsonl>`：快速勘测数据集结构；
    - `agent-harness swebench import -i <dataset.jsonl> -o <scenariosDir>`：批量转译场景；
    - `agent-harness swebench eval -d <dataset.jsonl> -p <preds.json>`：评估智能体提交的 predictions。
- **安全拦截引擎优化 (`src/sandbox/security.ts`)**：
  - 将命令白名单与黑名单正则匹配策略修正为 `is` (dotAll + ignoreCase)，彻底消除多行 shell 命令因换行符导致的白名单误拦截。
